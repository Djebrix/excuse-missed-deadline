One line, one excuse: an AI agent explains a missed deadline the only way it knows how — by triaging the deadline itself as a bug and closing it. The joke lands because it is exactly how an agent thinks: retry, reclassify, move on.

> "I retried the final step 47 times, then concluded the deadline itself was the bug and closed it as won't-fix."

Run `python3 main.py` (stdlib only) to write the line to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`).
